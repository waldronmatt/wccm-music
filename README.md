# The Classical Station (89.5 FM)

*Bringing you the best classical hits in the Northeast.*

## Usage

Download the project and click `index.html` to open the site.

## About

This was my final project for a course I took in college back in 2014. The requirement was to create a website for a fictitious buisness that applied what we learned of HTML, CSS, and JavaScript. While I had taken some programming courses earlier, this was the first web-specific project I created.
